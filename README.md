# 📘 C++ Project: MY C++ Project

## 📖 Overview
This project is a simple **C++ calculator** that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.  
It is designed as a beginner-friendly program to demonstrate fundamental concepts of C++ including input/output, conditional statements, and switch-case logic.

---

## 🚀 Features
- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division (with error handling for division by zero)  

---

## 🛠️ Technologies Used
- **Language:** C++  
- **Compiler:** g++ / Turbo C++ (or any standard C++ compiler)  
- **IDE (optional):** Visual Studio Code, CLion, or Code::Blocks
